# 観察者は観察対象である ― 実習アプリ

クリシュナムルティの言葉「観察者は観察対象である」を、頭の理解ではなく、日常の中で自分で見て体得するための実習アプリです。

- 記録は、あなたのスマホやパソコンの中にだけ残ります。どこにも送られません。
- ログインはありません。

---

## 文章の直し方

文章は、すべて `content` フォルダの中のファイルに入っています。プログラムを触らずに、文章だけを直せます。

| 直したいもの | ファイル | 直す所 |
| --- | --- | --- |
| 案内書の章の本文 | `content/guide.json` | 各章の `"body"` の中。一つの `"…"` が一つの段落です |
| 章の見出し・一行の要点 | `content/guide.json` | `"title"`(見出し)、`"point"`(要点) |
| つまずきの表 | `content/guide.json` | 第6章の `"rows"` |
| 七つの実習 | `content/practices.json` | `"aim"`(ねらい)、`"steps"`(手順)、`"example"`(例)、`"insight"`(見えてくること) |
| 30日の進め方 | `content/plan30.json` | `"periods"` |
| 自己点検表 | `content/checklist.json` | `"items"` |
| ACIMの原文 | `content/acim.json` | 各箇所の `"en": ""` の `""` の中に、英文を貼りつけます |
| 出典 | `content/sources.json` | |
| ボタンの言葉、短い案内、心の安全の文 | `content/ui.json` | |

### 直すときの注意(三つだけ)

1. 文章は、必ず `"` と `"` の間に書きます。
2. 文章の中で `"` を使いたいときは、かわりに「」を使ってください。
3. 行の終わりの `,`(カンマ)を消したり、増やしたりしないでください。

「恐れ」には、画面で自動的にふりがなが付きます。ファイルには、普通に「恐れ」と書いてください。

### ACIMの原文を入れる例

```json
"W-7": {
  "ja": "ワークブック 第7課。私は過去だけを見ている。",
  "url": "https://lessons.acim.org/en/chapters/lesson-7",
  "en": "ここに acim.org から貼りつけた英文"
},
```

## パソコンで動きを見る方法

`content` のファイルを読みこむため、`index.html` をダブルクリックしただけでは開きません。次のようにします。

1. ターミナルで、このフォルダに移ります。

```bash
cd ~/Documents/GitHub/kansatsusha-work
```

2. パソコンの中に、小さな表示用の仕組み(サーバー)を動かします。

```bash
python3 -m http.server 8765
```

3. ブラウザで http://localhost:8765 を開きます。終わるときは、ターミナルで `control` キーと `C` キーを同時に押します。

## 書いたことを、メモ帳に残す

実習の中で書いたことは、書いている途中でも「Markdownでコピー」を押すと、まとめてコピーできます。メモ帳やノートアプリに貼りつけて残せます。スマホでは「メモアプリへ送る」から、直接送ることもできます。
