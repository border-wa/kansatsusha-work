# 仕様書：「観察者は観察対象である」実習アプリ(公開版)

最終更新：2026-11-26(フェーズ2まで完成)

---

## 1. このアプリは何か

クリシュナムルティの言葉「観察者は観察対象である」を、頭の理解ではなく、日常の中で自分で見て体得するための実習アプリ。奇跡のコース(ACIM)の「赦し」へつなげる。

- 公開アドレス：https://border-wa.github.io/kansatsusha-work/
- リポジトリ：https://github.com/border-wa/kansatsusha-work(公開)
- 使う人：作者本人、ACIMやクリシュナムルティに関心のある一般の人。ACIMを知らない人にも分かるように書く。
- 使う場面：スマートフォンで一人で。ワークショップで画面を見せて使うこともある。

## 2. 大切にする考え方(すべての画面に共通)

| 決まり | 理由 |
| --- | --- |
| 点数・ランキング・達成率・連続記録・バッジ・回数を出さない | 「できた私」を育てると、それ自体が新しい観察者になるため |
| 進み具合は、記録が並ぶことだけで表す | 同上 |
| 「見えなかった」も、そのまま記録できる | それも「見えたこと」の一つ |
| 責める言葉・急かす言葉・ほめすぎる言葉を使わない | 心の中の裁判を増やさないため |
| 実習は、日程どおりにも、好きなときに、どこからでも、何回でもできる | 作者の希望 |

## 3. 技術の決まり

| 項目 | 内容 |
| --- | --- |
| 作り | HTML・CSS・JavaScript だけ。ビルド作業なし。ライブラリなし |
| 公開 | GitHub Pages(main ブランチの一番上) |
| 保存 | 端末のブラウザの中(localStorage)だけ。サーバーへは送らない |
| ログイン | なし |
| 外への送信 | なし。解析タグ・広告・外部フォントも読み込まない |
| 画面 | スマートフォン優先。幅 360px でも横スクロールなし |
| 文字 | 本文 17px、行間 1.8 |
| 色 | 落ち着いた緑。端末が暗い表示なら、自動で暗くなる |
| 保存できない端末 | 「この端末では記録が保存されません。」と一行出し、アプリは普通に動く |

## 4. ファイルの構成

```
kansatsusha-work/
├── index.html            入り口(画面は1枚の中で切り替える)
├── css/style.css         見た目
├── js/app.js             画面の切り替え
├── js/render.js          文章を画面の部品にする/ふりがな/コピー/タイマー
├── js/storage.js         保存(書きかけと記録)
├── content/              文章はすべてここ
│   ├── ui.json           ボタンや短い案内の言葉、心の安全の文
│   ├── guide.json        案内書の各章
│   ├── practices.json    七つの実習
│   ├── plan30.json       30日の進め方
│   ├── checklist.json    自己点検表
│   ├── acim.json         ACIMの原文欄
│   └── sources.json      出典
├── docs/                 この仕様書と取扱説明書
├── README.md             文章の直し方
└── CLAUDE.md             Claude Code が毎回守る決まり
```

**文章は content/ にだけ書く。** プログラム(js/)には日本語の文章を直接書かない。例外は、文章ファイル自体が読み込めなかったときの一行だけ。

## 6. 主な機能

### 6-1. 七つの実習

| 番号 | 題 | 書く欄 | タイマー | ACIM |
| --- | --- | --- | --- | --- |
| 1 | 動作の中に、言葉が割りこむ瞬間 | 割りこんだ言葉 | ― | ― |
| 2 | 人を、像を通して見ている | 像を3つ/いつの記憶から3つ | ― | W-7 |
| 3 | 怒りの瞬間と、その一秒後 | 来た言葉 | ― | ― |
| 4 | 観察者の声を、書き出す | 聞こえた言葉3つ/誰の言い方3つ | ― | M-10.2 |
| 5 | 「これは、私と別のものか」 | なし | 3分 | ― |
| 6 | 直そうとする動きを、見る | なし | ― | 聖霊に差し出す言葉 |
| 7 | 関係という鏡と、赦し | 三つの問いそれぞれ | ― | 最後の画面の祈りの言葉 |

- 書いたことは、書いている途中でも端末に残る(書きかけ)。
- 実習2・4では、前の手順で書いた言葉が、次の欄の上に出る。
- 「もう一度する」「書いたことを消して、はじめから」は、消す前に一度確かめる。

### 6-2. 今日、見えたことの記録

一件の記録が持つもの:

| 項目 | 中身 |
| --- | --- |
| 日付と時刻 | 自動 |
| 本文 | 一行から数行。空でもよい(見えなかったの印があれば) |
| 実習の番号 | 1〜7、またはなし |
| 見えなかった | 印のあり・なし |
| どこから | 記録の画面/実習のおわり/一秒後の問い |
| 実習で書いたこと | 欄の名前と中身の組 |

- 一日に何件でも書ける。
- 一覧は新しい順。「すべて」か実習の番号で絞り込める。
- 直す・消すができる。消す前に一度だけ確かめる。
- 表示している記録を、Markdown にしてまとめてコピーできる。

### 6-3. タイマー

- 実習5(3分)の手順の中に出る。
- 残り時間は小さな数字で、主には円の減り方で見せる。
- 始める/止める/続ける/もう一度。
- 終わると、短い振動(できる端末だけ)と、円のやわらかい明滅で知らせる。音は出さない。
- 別の画面に移ると止まる。

### 6-4. 一秒後の問い

- ホームの一番上の大きなボタンから、一回のタップで開く。
- 大きな文字で一行:「今、裁いているのは誰か。それは、裁かれているものと、別か。」
- 呼吸を促す円が、8秒で大きくなって小さくなる。音は出さない。
- 「閉じる」と「一行メモする」だけ。メモは書かなくてもよい。書いたメモは記録に入る。

### 6-5. Markdownでコピー

- 実習の書く欄がある画面と、おわりの画面、記録の一覧にある。
- 題・日時・書いたことを Markdown の形にしてコピーする。メモ帳に貼りつけられる。
- スマホでは「メモアプリへ送る」も出る(端末が対応していれば)。
- 押したときだけ動く。自動では何も送らない。

## 7. 表記の決まり

- 「手放す」「手放し」は使わない。「訂正」「取り消し」「赦し」を使う。
- 認識の上で分けることは「区別」。「分離」はACIMの「神からの分離」の意味だけ。
- 「赦し」と「許し」を混同しない。
- 「罪はない。あったのは誤りだけ。誤りは罰するものではなく、訂正されるもの」という立場を崩さない。
- 「恐れ」には画面でふりがな(おそ)を付ける。content には普通に「恐れ」と書けば、自動で付く。
- 一文は短く、小学五年生にも分かる言葉で。「〜してみてください」「〜でかまいません」。
- ACIMの英文は記憶で書かない。公式サイトから取ったものだけを入れる。まだのものは「準備中」と出す。
- クリシュナムルティの言葉は日本語の要約で示し、「要約」と書く。

## 8. 心の安全の表示

| 場所 | 表示 |
| --- | --- |
| 案内書 第6章、設定 | 「実習の中で、強い苦しさが続く、現実感が薄くなる、眠れない、ということがあれば、実習を休んでください。……」 |
| 実習5・実習7の始まり | 「つらさが強いときは、今日は休んでかまいません。」 |

この表示は削除・弱体化しない。医療的な診断や助言に見える表現は入れない。
