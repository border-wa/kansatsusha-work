# 取扱説明書：「観察者は観察対象である」実習アプリ

このアプリは、「観察者は観察対象である」という言葉を、自分の目で見て確かめるための実習帳です。
読む時間より、見る時間を長くしてみてください。

---

## はじめに

### 開き方

スマホやパソコンのブラウザで、次のアドレスを開きます。

**https://border-wa.github.io/kansatsusha-work/**

ログインはいりません。

### ホーム画面に置く(おすすめ)

アプリのように、一回のタップで開けるようになります。

- **iPhone**：Safari で開く → 下の共有ボタン(四角から矢印が出ている形)→「ホーム画面に追加」
- **Android**：Chrome で開く → 右上の「︙」→「ホーム画面に追加」

### 書いたことは、どこに残るか

- 書いたことは、**その端末のブラウザの中だけ**に残ります。どこにも送られません。
- 別のスマホやパソコンには出てきません。
- ブラウザの「履歴とデータを消す」をすると、記録も消えます。大切な記録は「Markdownでコピー」で、メモ帳に残しておいてください。
- プライベートブラウズでは、記録が残りません。そのときは画面の上に「この端末では記録が保存されません。」と出ます。

---

## 画面の見方

画面の一番下に、4つのタブがあります。

| タブ | できること |
| --- | --- |
| ホーム | 一秒後の問い、今日の実習、今日見えたことを書く |
| 案内書 | 指導書を章ごとに読む |
| 実習 | 七つの実習をする |
| 記録 | 今日見えたことを書く、これまでの記録を見る |

ホームの一番下には「自己点検」「設定」「出典」があります。

---

## 使い方

### 1. 反応した直後に ―「一秒後の問い」

イラッとした、ムッとした、すぐあとに使います。

1. ホームの一番上の **「一秒後の問い」** を押します。
2. 大きな文字で、問いが一行だけ出ます。
   「今、裁いているのは誰か。それは、裁かれているものと、別か。」
3. 円がゆっくり大きくなって、小さくなります。それに合わせて、息をしてみてください。
4. 終わったら **「閉じる」**。
   何か見えたら **「一行メモする」** → 書く → **「残す」**。メモは「記録」に入ります。

書かなくてもかまいません。

### 2. 実習をする

1. 下の **「実習」** タブを押します。
2. 七つの実習から、一つ選びます。どれからでも、何回でもかまいません。
3. ねらいと目安の時間を見て、**「始める」**。
4. 手順が一つずつ出ます。**「次へ」** で進み、**「戻る」** で戻れます。
5. 書く欄がある手順では、思ったことをそのまま書いてみてください。書かなくても進めます。
6. 最後の **「おわり」** の画面で、「見えたこと」を書いて **「記録に残す」** を押すと、記録に入ります。

#### タイマー(実習1と実習5)

- **「始める」** で円が減り始めます。
- 途中で **「止める」**、**「続ける」** ができます。
- 時間になると、短く振動して(できる端末だけ)、円がやわらかく明滅します。音は出ません。

#### 書きかけ

- 書いたことは、書いている途中でも残ります。途中で閉じても、次に開くと続きから書けます。
- はじめからやり直すときは、実習の始まりの画面で **「書いたことを消して、はじめから」** を押します。

### 3. 今日、見えたことを書く

1. 下の **「記録」** タブ(または、ホームの「今日、見えたことを書く」)を押します。
2. 一番上の欄に、今日見えたことを書きます。一行でかまいません。
3. 関係する実習があれば、番号を選びます。なければ「なし」のままで大丈夫です。
4. 何も見えなかった日は、**「見えなかった」** に印を付けます。それも、見えたことの一つです。
5. **「残す」** を押します。

一日に何件でも書けます。

### 4. 記録を見る・直す・消す

「記録」タブの下のほうに、これまでの記録が新しい順に並びます。

- **絞り込み**：「すべて」か、実習の番号を押すと、その実習の記録だけが出ます。
- **直す**：記録の下の「直す」→ 書き直す →「直したものを残す」。
- **消す**：記録の下の「消す」→ 確かめの画面で「OK」。消した記録は戻せません。
- **まとめてコピー**：「表示している記録を、まとめてコピー」で、いま出ている記録を全部コピーできます。

### 5. メモ帳に残す ―「Markdownでコピー」

- 実習の画面と記録の画面にある **「Markdownでコピー」** を押すと、書いたことが題・日時つきでコピーされます。
- メモ帳やノートアプリに貼りつけて、控えにできます。
- スマホでは **「メモアプリへ送る」** から、直接送ることもできます。

### 6. 案内書を読む

「案内書」タブで、指導書を章ごとに読めます。各章の一番上に、その章の要点が一行で出ます。

### 7. 出典を見る

ホームの一番下の「出典」から、クリシュナムルティと奇跡のコースの元のページへ行けます(英語)。

## 困ったとき

| こんなとき | こうしてみてください |
| --- | --- |
| 記録が消えた | ブラウザのデータを消したか、別のブラウザ・別の端末で開いていないか確かめてください |
| 「この端末では記録が保存されません。」と出る | プライベートブラウズをやめて、普通の画面で開いてください |
| 「文章を読みこめませんでした」と出る | 電波のある所で、ページを開き直してください |
| コピーできない | 出てきた文字を長押しして、選んでコピーしてください |
| タイマーで振動しない | 振動に対応していない端末です。円の明滅で知らせます |
| 新しくした内容が出てこない | ページを開き直してください |

---

## 心の安全のために

実習の中で、強い苦しさが続く、現実感が薄くなる、眠れない、ということがあれば、実習を休んでください。これは休む合図であって、進歩の合図ではありません。続く場合は、医師や心理の専門家に相談してください。
